## 📱 About Brix Hax

Brix Hax is an Android project for Minecraft Bedrock Edition. It provides an in-game overlay interface and a module menu for accessing the features included in the installed build.

The app uses a local networking/relay approach in its Bedrock connection workflow. Compatibility and behaviour can vary depending on the Android device, Minecraft version, app build, network, and server configuration.

## ✨ Features

- **Overlay interface** — access the menu while using the app.
- **Module menu** — view and manage modules available in the installed build.
- **Floating menu button** — quick access to the overlay.
- **Animated interface** — menu and button animation refinements.
- **APK releases** — download builds from GitHub Releases.

Feature availability may differ between versions. Compatibility with every server or Minecraft release is not guaranteed.
